# Todo App

A browser-based task list built as a freeCodeCamp JavaScript coding assignment. Add tasks with a title, date, and description, then edit or delete them. Tasks are saved in your browser using `localStorage`, so they remain available when you reopen the app in the same browser.

## Run locally

No installation or build tools are required:

1. Clone or download this repository.
2. Open `todo App/index.html` in a browser.
3. Select **Add New Task** to create a task.

## Features

- Create tasks with a required title and optional date and description.
- Edit existing tasks or delete tasks you no longer need.
- Save tasks in browser `localStorage`.
- Confirm before discarding unsaved form changes.
